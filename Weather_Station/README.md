# Weather Station 

## NOTE:
This will heavily use and reference the [Database_Development](https://github.com/mn19-RSE/Database_Development) repo.

## Purpose:
This is a learning project to develop HMI Python code for use on a Raspberry Pi. This may be used in another project in this repo. The goal of this project is to be able to display data pulled from a free public weather API on a display connected to a Raspberry Pi via HDMI.
